
WIRELESS EV CHARGING SYSTEM

PROJECT OVERVIEW

The Wireless EV Charging System is an engineering project developed to demonstrate wireless power transfer using electromagnetic induction. The system uses transmitter and receiver coils to transfer electrical energy without direct physical connections.

OBJECTIVES

- To demonstrate wireless power transfer.
- To develop a simple wireless EV charging prototype.
- To understand electromagnetic induction.
- To use an IR sensor for object detection.
- To control the charging process using Arduino UNO.

COMPONENTS USED

1. Arduino UNO
2. IR Sensor
3. D882 Transistor
4. Transmitter Coil
5. Receiver Coil
6. DC Power Supply
7. LED Indicator

WORKING PRINCIPLE

The IR sensor detects the presence of an object and sends a signal to the Arduino UNO. The Arduino controls the D882 transistor, which drives the transmitter coil.

The transmitter coil generates an electromagnetic field. The receiver coil captures this field and generates electrical voltage through electromagnetic induction.

This demonstrates wireless power transfer without direct electrical contact.

RESULTS

- Successful demonstration of wireless power transfer.
- IR sensor detects the presence of an object.
- Receiver coil generates measurable output voltage.
- Working distance demonstrated approximately 1 to 5 cm.

APPLICATIONS

- Electric Vehicle Wireless Charging
- Wireless Power Transfer Systems
- Contactless Charging Technology
- Smart Charging Infrastructure

FUTURE SCOPE

- Improving power transfer efficiency.
- Increasing wireless charging distance.
- Developing automatic charging systems.
- Adding advanced safety features.
- Improving the prototype for practical EV applications.

CONCLUSION

The Wireless EV Charging System successfully demonstrates the basic concept of wireless power transfer using electromagnetic induction. This project provides a foundation for understanding and developing future wireless EV charging technologies.
