WIRELESS EV CHARGING SYSTEM

PROJECT OVERVIEW

The Wireless EV Charging System is an engineering project developed to demonstrate wireless power transfer using electromagnetic induction. The system uses transmitter and receiver coils to transfer electrical energy without direct physical connections.

OBJECTIVES

- To demonstrate wireless power transfer.
- To develop a simple wireless EV charging prototype.
- To understand electromagnetic induction.
- To use IR sensors for object detection.
- To control the charging process using Arduino UNO.

COMPONENTS USED

1. Arduino UNO
2. IR Sensors
3. D882 Transistors
4. Transmitter Coils
5. Receiver Coil
6. DC Power Supply
7. LED Indicator

ARDUINO PIN CONFIGURATION

IR Sensor Inputs:
- IR Sensor 1: Pin 2
- IR Sensor 2: Pin 3
- IR Sensor 3: Pin 4

Coil Outputs:
- Coil Set 1: Pin 8
- Coil Set 2: Pin 9
- Coil Set 3: Pin 10

WORKING PRINCIPLE

The IR sensors detect the presence of an object and send signals to the Arduino UNO.

The Arduino controls the D882 transistors, which control the transmitter coils.

The transmitter coils generate an electromagnetic field. The receiver coil captures this field and generates electrical voltage through electromagnetic induction.

This demonstrates wireless power transfer without direct electrical contact.

EXPERIMENTAL SETUP

The prototype consists of an Arduino UNO, IR sensors, D882 transistors, transmitter coils and a receiver coil.

The system was tested by detecting an object using IR sensors and controlling the transmitter coils.

RESULTS AND DISCUSSION

- Successful demonstration of wireless power transfer.
- IR sensors detect the presence of an object.
- Receiver coil generates measurable output voltage.
- Working distance demonstrated approximately 1 to 5 cm.

APPLICATIONS

- Wireless Power Transfer Systems

ADVANTAGES

- No direct electrical connection required.
- Automatic object detection.
- Simple control using Arduino UNO.
- Demonstrates electromagnetic induction.

LIMITATIONS

- Limited wireless power transfer distance.
- Power transfer efficiency depends on coil alignment.
- Output power depends on the coil design and circuit configuration.

FUTURE SCOPE

CONCLUSION

The Wireless EV Charging System successfully demonstrates the basic concept of wireless power transfer using electromagnetic induction.

This project provides a foundation for understanding and developing future wireless EV charging technologies.
